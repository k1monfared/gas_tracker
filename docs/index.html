Features

Manual or odometer entry

Enter distance driven or current odometer reading. The app computes the rest.

Photo / OCR entry

Take or pick photos of the pump or odometer. Tesseract OCR extracts values and the app classifies the photo type.

Dashboard

Track cost per period, efficiency in L/100km and MPG, and average price per liter.

Private and offline

Data stays on your device. Optional FX conversion uses cached ECB rates.

Install

Download the latest APK from GitHub Releases and open it on your Android 10+ device.

For automatic updates, use Obtainium pointed at this repository.

Build from source

git clone https://github.com/k1monfared/gas_tracker.git
cd gas_tracker/android
./gradlew assembleDebug
# APK at app/build/outputs/apk/debug/app-debug.apk
